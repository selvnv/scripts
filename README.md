# Репозиторий скриптов автоматизации

Коллекция вспомогательных скриптов для администрирования и автоматизации рутинных задач.

Скрипты сгруппированы по языку реализации в подкаталогах (например, `python/`).

## Скрипты

### check_ports

Файл: [`python/check_ports.py`](python/check_ports.py)

Определяет, какие TCP- и UDP-порты заняты на Linux-машине, и выводит их в удобном для чтения виде — сгруппированными в диапазоны.

**Зачем нужен.** Позволяет быстро выяснить, какие сетевые порты уже используются. Это полезно при выборе свободного порта для нового сервиса, диагностике конфликтов портов или проверке того, что нужные сервисы действительно слушают свои порты.

**Как работает.** Скрипт не полагается на внешние утилиты (`ss`, `netstat`, `lsof`), а читает данные напрямую из виртуальной файловой системы `/proc`:

- TCP — `/proc/net/tcp` и `/proc/net/tcp6`;
- UDP — `/proc/net/udp` и `/proc/net/udp6`.

Для TCP учитываются только порты в состоянии `LISTEN` — те, на которых сервер ожидает входящие подключения. У UDP состояния подключения нет, поэтому учитываются все занятые порты. Номера портов переводятся из шестнадцатеричного формата в десятичный, дедуплицируются, сортируются по возрастанию и сворачиваются в диапазоны (например, `80, 443-445`).

**Запуск.**

```bash
python3 python/check_ports.py
```

**Пример вывода.**

```text
TCP: 22, 80, 443, 8000-8002
UDP: 53, 123, 5353
```

**Ограничения.**

- Работает только на Linux: используется `/proc`, которого нет в Windows и macOS.
- Показывает только порты, доступные текущему пользователю для чтения (программа может прочитать только те данные, к которым у пользователя, запустившего скрипт). Используемые файлы, как правило, доступны для чтения обычному пользователю
- Не показывает, какой процесс занимает порт (для этого нужно использовать `ss`, `netstat` или `lsof`).
